# E-Commerce Sales & Customer Analytics

An end-to-end Data Analyst portfolio project analyzing e-commerce sales, customers, products, profitability, and returns using Python, Pandas, MySQL, Excel, and Power BI.

---

## 📌 Project Overview

This project analyzes an e-commerce dataset to understand overall business performance and identify opportunities to improve sales, profitability, customer retention, and return management.

The project follows a complete data analytics workflow:

**Data Cleaning → Feature Engineering → SQL Analysis → Dashboard Development → Business Insights**

---

## 🎯 Business Problem

The business wants to understand:

- Which categories generate the most revenue and profit?
- Which products perform best?
- Which customers generate the highest value?
- How are sales changing over time?
- What percentage of orders are returned?
- Why are customers returning products?
- Which categories and periods have the highest return activity?
